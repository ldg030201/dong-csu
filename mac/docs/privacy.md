# 사용량과 토큰

[← README](../README.md)

## 어디서 읽나

keychain 항목 `Claude Code-credentials`에서 OAuth 토큰을 읽어
`GET https://api.anthropic.com/api/oauth/usage`를 호출하고, 응답의
`five_hour.utilization` / `seven_day.utilization`(각 0~100)을 링에 그린다.

이 조회는 **모델을 부르지 않는다.** 계정 사용량만 읽는 엔드포인트라 토큰을 전혀 쓰지 않는다.

## 토큰을 어떻게 다루나

- `/usr/bin/security`로 읽고 쓴다. Apple이 서명한 고정 바이너리라 keychain에서 "항상 허용"을
  한 번 눌러두면 앱을 다시 빌드하거나 버전을 올려도 다시 묻지 않는다
- **Authorization 헤더로만** 쓰이고 **로그에 남기지 않는다.** 화면이든 진단 통로든
  토큰 값을 찍는 자리가 없다
- 갱신해서 받은 토큰만 `~/Library/Application Support/com.ldg.dong-csu/token.json` 에
  둔다. 파일은 `-rw-------`, 폴더는 `drwx------` 로 **본인만 읽을 수 있다**
- 그 밖에 저장하는 건 창 위치, 아이콘·크기 선택, 숨김 여부뿐이다

## 어디에 접속하나

| 대상 | 언제 |
| --- | --- |
| `api.anthropic.com` | 사용량 조회 (기본 10분마다) |
| `raw.githubusercontent.com` | 새 버전 확인과 변경 내역 (하루 1회, 끌 수 있음) |

그 외에는 접속하지 않는다. 통계·추적 없고 외부 Swift 패키지 의존성도 0개다.
버전 탭에서 업데이트 확인을 끄면 Anthropic API 외에 아무 데도 접속하지 않는다.

## 권한은 쓰지 않는다

이 앱은 손쉬운 사용(Accessibility)·화면 녹화 같은 권한을 요청하지 않는다.
keychain 접근 한 번이 전부다.

펫이 글을 쓰는 동안 가만히 있으려면 "지금 타이핑 중인가"만 알면 되는데, 그건
`CGEventSource.secondsSinceLastEventType`이 주는 **마지막 키 입력 뒤 흐른 초**로
충분하고 권한 없이 읽힌다. macOS가 화면 보호기를 띄울 때 쓰는 것과 같은 값이다.

**무슨 키를 눌렀는지는 이 값에 들어 있지 않다.** 입력 내용을 알 수 있는 통로가 아니다.

## 조회 주기

기본 10분이고 1·3·5·10·30분 중에 고를 수 있다. 조회가 나갈 때마다 그 시점부터 다시 세므로,
수동으로 새로고침하면 다음 자동 조회도 그만큼 밀린다.

화면이 꺼지면 멈추고, 켜지거나 절전에서 깨어나면 즉시 한 번 갱신한다.
429가 오면 최대 5분까지 백오프한다.

유휴 상태에서 쓰는 자원은 CPU 0.2% 안팎, 메모리 22MB(`phys_footprint`) 정도다.
CPU·메모리 표시를 켜면 2초마다 표본을 떠서 조금 더 쓴다.

## 토큰이 만료되면

Claude Code의 액세스 토큰은 수명이 8시간이라 종종 만료된다. **앱이 알아서 갱신한다** —
keychain에 같이 들어 있는 리프레시 토큰으로 새 토큰을 받는다. 리프레시 토큰까지 죽었을
때만 `재로그인 필요`로 바뀌고, 메뉴의 `Claude Code 재로그인…`이 터미널에서 로그인
플로우를 연다.

### 왜 keychain에 되쓰나

서버는 갱신할 때마다 **새 리프레시 토큰을 주고, 방금 쓴 것은 즉시 죽인다.** 그래서 우리가
갱신만 하고 말면 keychain에 남은 값이 그 순간 무효가 되어 **Claude Code 로그인이 풀린다.**
그걸 막으려고 새로 받은 값을 원래 자리에 되돌려 쓴다.

읽기와 같은 `/usr/bin/security`를 쓴다. 앱이 직접 keychain을 고치면 허락이 **코드 서명
신원**에 걸리는데, 이 앱은 신원 대신 바이너리 해시로 식별돼서 **버전을 올릴 때마다 다시
물어야 한다.** `security`는 신원이 고정이라 처음 한 번으로 끝난다. 명령은 표준 입력으로
넘겨서 **토큰이 프로세스 목록에 드러나지 않는다.**

되돌려 쓰기가 실패하면 그대로 둔다 — 앱은 제 사본으로 계속 돌고, 같은 것을 반복해서
묻지 않는다.
