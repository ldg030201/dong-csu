# 플랫폼끼리 나눠 쓰는 것

[← README](../README.md)

여기 있는 파일은 **손으로 고치지 않는다.** 맥 소스에서 뽑아낸 것이고, 뽑는 명령이
따로 있다. CI가 소스와 다르면 실패시킨다.

| 파일 | 무엇 | 뽑는 법 |
| --- | --- | --- |
| `owl.json` | 부엉이 그리드·색·기분별 프레임표 | `cd mac && source ./lib.sh && dump_owl` |

## 왜 이렇게 하나

윈도우판이 같은 부엉이를 그리려면 그리드와 색과 프레임 시간이 필요하다.
그걸 옮겨 적으면 **맥에서 자세를 하나 고칠 때마다 어긋난다.** 어긋난 걸 사람이
기억해서 맞추는 방식은 오래 못 간다.

그래서 맥 소스를 **유일한 원본**으로 두고 파일은 거기서 뽑는다. 이 저장소가
변경 내역(`Changelog.swift` → `docs/changelog.json`)에 이미 쓰고 있는 방식이다.

## `owl.json` 읽는 법

```
formatVersion    형식이 바뀌면 올라간다. 모르는 값이면 읽지 마라
grid             columns 15 · lines 13 · bodyColumns 11
layers           이름 → 13줄짜리 문자열. '.' 은 빈 칸
palettes         normal / offline / test → 글자별 색(hex)
moodThresholds   tired 80 · exhausted 95 (5시간 세션 사용률)
usageColors      링 색 구간. 사이는 선형 보간
animations       기분 6 + 걸음걸이 2
```

글자 한 개가 색 하나다.

| 글자 | 파츠 | 팔레트 키 |
| --- | --- | --- |
| `#` | 몸통·발 | `body` |
| `d` | 날개 | `wing` |
| `l` | 배 무늬 | `belly` |
| `w` | 눈 흰자 | `face` |
| `k` | 눈동자·눈꺼풀 | `pupil` |
| `y` | 부리 | `beak` |

### 프레임마다 두 가지가 들어 있다

- `pose` — 어떤 레이어를 어떻게 밀어 겹치는지
- `grid` — **그 합성이 끝난 결과**

`grid` 만 그려도 애니메이션이 나온다. `pose` 는 끌림처럼 **그때그때 자세를 만드는**
경우에 필요하고, 그걸 구현했으면 `grid` 와 비교해서 맞는지 확인하면 된다 —
그림을 그려보지 않고 텍스트만으로 검증된다.

> 한 칸은 반드시 **정수 크기**로 그려야 한다. 나누어떨어지지 않는 크기로 그리면
> 어떤 행은 2px, 어떤 행은 3px가 되어 자리마다 다른 얼굴이 된다.
> 자세한 배경은 [부엉이 문서](../docs/characters/owl.md).
