# 문제 해결

무엇이든 막히면 **설정 창 계정 탭**을 먼저 연다. 어디를 찾아봤고 왜 못 읽었는지가
거기 그대로 적혀 있다. 그래도 모르겠으면 **기록 열기** 를 누른다.

```
%APPDATA%\DongCSU\log.txt
```

**토큰은 기록에 안 남는다** — 경로와 성공·실패만 적는다.

---

## 사용량이 안 나온다

### "로그인 정보를 찾지 못했습니다"

Claude Code 가 아직 아무것도 저장한 적이 없다. **Claude 앱이나 Claude Code 에서 한 번
대화해 보면** `~/.claude/.credentials.json` 이 만들어진다. 터미널은 필요 없다.

**WSL 안에서 Claude Code 를 쓴다면** 윈도우 홈에는 아무것도 없다. 그것도 찾아보게
돼 있지만, WSL 이 꺼져 있으면 못 읽는다 — 한 번 켜고 새로고침한다.

### "파일은 있는데 Claude 로그인이 안 들어 있습니다"

MCP 토큰만 든 파일이 그렇다. Claude 로 한 번 대화하면 채워진다.

### "토큰이 만료됐고 갱신도 실패했습니다"

갱신용 토큰까지 죽었다. 계정 탭의 **Claude Code 재로그인…** 을 누르면 창이 하나 열리고,
거기서 로그인을 마치면 30초쯤 뒤에 조회가 다시 시작된다.

> 평소에는 여기까지 오지 않는다. 만료된 토큰은 앱이 스스로 갱신한다.

### 숫자가 오래돼 보인다

HUD 에 **회색**이 돌면 지금 값이 아니라는 뜻이다. 새로고침을 눌러 본다.

새로고침이 `(N초)` 로 잠겨 있으면 그만큼 기다린다 — **조회 사이에 최소 10초를 둔다.**
안 그러면 서버가 요청 제한을 걸어서 한동안 아무것도 안 나온다.

---

## 창이 안 보인다

### 껐는데 다시 켤 곳을 못 찾겠다

작업 표시줄에 안 나오는 앱이라 그렇다. **시작 메뉴에서 `DongCSU`** 를 찾는다.
설치본은 시작 메뉴와 바탕화면에 바로가기를 만들어 둔다.

### 화면 밖으로 나갔다

설정 창 **표시** 탭의 **위치 초기화** 를 누른다.

### 다른 창에 가린다

늘 위에 뜨게 돼 있다. 전체화면 게임처럼 화면을 독차지하는 것 위에는 못 뜬다.

---

## 펫 모드

### 안 걸어다닌다

이럴 때는 일부러 멈춘다 — **잡고 있는 동안 · 글을 쓰는 동안 · 화면이 잠긴 동안 ·
조회가 끊긴 동안 · 주간 한도를 다 썼을 때.**

글을 쓰는 동안 멈추는 것은 키 입력을 보고 판단한다. **무슨 키를 눌렀는지는 안 본다** —
마지막으로 누른 시각만 잰다.

### 커서를 안 피한다

설정 **펫** 탭에서 `커서 피하기` 를 켠다. 글을 쓰는 중이면 비키지 않는다.

### 집어 들면 링이 사라진다

그렇게 돼 있다. 싫으면 펫 탭의 `들고 있을 때 감추기` 를 끈다.

---

## 업데이트

### "설치본이 아니라 자동 업데이트를 쓸 수 없습니다"

압축을 풀어서 쓰거나 개발 빌드를 돌리는 중이다. 설치본으로 깔면 된다.

### 받다가 멈춘 것 같다

**갈아끼우는 중** 이라고 뜬 채로 한참 있으면 **강제 종료** 를 누른다. 그 뒤에는
설치본을 다시 받아 깔면 원래대로 돌아온다.

### 테스트판이라 업데이트가 안 된다

`DongCSU-Test` 는 일부러 업데이트하지 않는다. 개발용이다.
