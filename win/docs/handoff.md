# 윈도우 쪽에서 이어받을 때

[← 윈도우판 README](../README.md) · 작업 규칙은 [`../CLAUDE.md`](../CLAUDE.md)

윈도우판은 **맥에서, 화면을 한 번도 보지 못한 채로** 만들어졌다. WPF 가 맥에서
컴파일되지 않아 확인 수단이 CI 빌드와 테스트뿐이었다. 그래서 화면에 관한 것은
아무것도 검증되지 않았고, 그걸 확인하는 일이 윈도우 쪽에서 할 첫 번째 일이다.

아래 글을 그대로 윈도우의 Claude Code 에 붙여 넣으면 된다.

---

```
이 저장소(dong-csu)의 윈도우판 개발을 이어받아 줘.

먼저 이 세 문서를 읽어:
  win/CLAUDE.md   윈도우 전용 작업 규칙 — 프로젝트 구성, 진단 통로, 배포, 그릴 때 걸리는 것
  CLAUDE.md       공통 규칙 — 버전 자리, 변경 내역 문구, 커밋 규칙
  win/README.md   사용자에게 보이는 설명

배경:
윈도우판은 맥에서 만들어졌는데, WPF 가 맥에서 컴파일되지 않아 **화면을 한 번도 보지
못한 채** 짜였다. 확인 수단이 CI 빌드와 테스트뿐이었다. 너는 윈도우에 있으니 실제로
띄워 볼 수 있다. 그게 여기서 할 수 있는 가장 값어치 있는 일이다.

지금 상태:
- 최신 릴리스는 win-v1.1.1, 안 나간 변경은 없다
- 펫 모드(혼자 돌아다니기·커서 피하기)는 아직 없다. 언제 넣을지도 안 정했다
- 맥판은 2.1.2 이고, 기능은 맥에서 먼저 만들어 윈도우로 옮긴다

첫 번째로 해 줬으면 하는 것 — 아래 두 가지가 실제로 고쳐졌는지 확인:

  1) 사용량이 "토큰 만료"로 안 나오던 문제
     %USERPROFILE%\.claude\.credentials.json 이 있고 Claude 도 켜져 있는데 만료로 떴다.
     원인은 파일에 적힌 만료 시각만 보고 API 를 한 번도 부르지 않은 것이었고,
     서버가 판단하도록 1.1.1 에서 고쳤다. 확인은 안 됐다.

  2) 업데이트를 누르면 앱만 꺼지고 갱신이 안 되던 문제
     Velopack 은 우리 프로세스가 끝나야 파일을 바꾸는데, 트레이 아이콘과 창을 살려 둔
     채로 불러서 업데이터가 물러난 것으로 보인다. 갈아 끼우기 전에 정리하도록 1.1.1 에서
     고쳤다. 이것도 확인 안 됐다.

  둘 다 %APPDATA%\DongCSU\log.txt 에 어디서 멈췄는지 남는다.
  DongCSU.exe --probe 로 자격 증명과 조회만 따로 확인할 수도 있다.

그다음 — 눈으로 봐야만 알 수 있는 것들을 봐 줘:
  HUD 배치(240×88 안에 글자가 다 들어가나, Segoe UI 가 넓어 오른쪽이 잘리지 않나)
  부엉이가 링 안에 제대로 들어가나
  링이 0%·50%·100% 에서 제대로 그려지나
  투명 배경·항상 위·드래그·더블클릭
  트레이 아이콘이 보이고 눈을 깜빡이나
  설정 창 네 탭이 잘리는 데 없이 그려지나

지켜야 할 것:
- 부엉이 그림을 여기서 고치지 마라. 원본은 맥 소스이고 shared/owl.json 으로 넘어온다.
  레이어 겹치기(OwlComposer)만 옮겨 적혀 있고, 테스트가 전 프레임을 맥의 결과와 대조한다
- 화면이 아닌 것은 DongCSU.Core 에 둬라. 거기 있어야 어디서나 테스트된다
- 윈도우는 버전 네 번째 자리를 못 쓴다(설치본이 SemVer2 세 자리만 받는다).
  긴급 수정도 세 번째 자리로 올린다
- **버전 자리를 정하거나 태그를 붙이기 전에 반드시 나에게 물어봐라**
- 커밋은 제목 한 줄만. 이모지 하나 + 한국어 한 줄

먼저 문서를 읽고, 앱을 띄워 보고, 무엇이 되고 무엇이 안 되는지 알려 줘.
고치는 건 그다음에 이야기하자.
```

## 맥 쪽에서 옮겨 올 것

윈도우에 아직 없는 것들이다. 급하지 않지만 언젠가 맞춰야 한다.

| 맥에 있는 것 | 윈도우 |
| --- | --- |
| 펫 모드 (혼자 돌아다니기 · 커서 피하기) | 없음 |
| 마스코트 애니메이션 끄기 | 없음 |
| 모든 설정 초기화 | 없음 |
| 아이콘 고르기 (Clawd · Claude 아이콘 · 버스트 마크) | 부엉이만 |
| HUD 크기 4단계 · 배경 불투명도 | 크기만 있음 |

**옮길 때도 화면 없는 부분을 먼저 `Core` 에 넣고 테스트로 굳혀라.** 맥 쪽 구현은
`mac/Sources/DongCSU/` 에 있고, 규칙과 이유는 [`mac/CLAUDE.md`](../../mac/CLAUDE.md) 에 있다.
