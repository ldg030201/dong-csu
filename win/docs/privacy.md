# 사용량과 토큰

[← README](../../README.md)

## 어디서 읽나

Claude Code 가 저장해 둔 `.credentials.json` 에서 OAuth 토큰을 읽어
`GET https://api.anthropic.com/api/oauth/usage` 를 부르고, 응답의
`five_hour.utilization` / `seven_day.utilization`(각 0~100)을 링에 그린다.

이 조회는 **모델을 부르지 않는다.** 계정 사용량만 읽는 자리라 토큰을 한 개도 쓰지 않는다.

찾아보는 자리는 이렇다. 어디를 봤고 왜 못 읽었는지는 설정 창 **계정** 탭에 그대로 뜬다.

| | |
| --- | --- |
| 윈도우 홈 | `%USERPROFILE%\.claude\.credentials.json` |
| 옮겨 둔 자리 | `%CLAUDE_CONFIG_DIR%\.credentials.json` |
| **WSL 안** | `\\wsl$\<배포판>\home\<사용자>\.claude\.credentials.json` |

WSL 은 **앞의 둘에서 못 찾았을 때만** 본다 — 들여다보는 것 자체가 비싸고, 꺼져 있는
배포판을 깨울 수 있다.

## 토큰을 어떻게 다루나

- **Authorization 헤더로만** 쓰이고 **기록에 남기지 않는다.** 화면이든 진단 통로든
  토큰 값을 찍는 자리가 없다 — 경로와 성공·실패만 적는다
- Claude Code 의 `.credentials.json` 은 **읽기만 한다.** 우리가 고치지 않는다
- 갱신해서 받은 토큰만 `%APPDATA%\DongCSU\token.json` 에 둔다. 그 폴더에 **남의 권한이
  끼어 있으면 지운다** — 평소에는 아무것도 안 한다(윈도우가 물려주는 권한이 이미
  {본인 · SYSTEM · Administrators} 뿐이라 유닉스의 `0700` 과 같다)
- 그 밖에 저장하는 건 창 위치, 아이콘·크기 선택, 숨김 여부뿐이다

## 어디에 접속하나

| 대상 | 언제 |
| --- | --- |
| `api.anthropic.com` | 사용량 조회 (기본 10분마다) |
| `raw.githubusercontent.com` | 변경 내역 (하루 1회, 끌 수 있음) |
| `github.com` | 새 버전 확인·내려받기 (하루 1회, 끌 수 있음) |

그 외에는 접속하지 않는다. 통계·추적이 없다. 버전 탭에서 업데이트 확인을 끄면
Anthropic API 말고 아무 데도 접속하지 않는다.

## 키 입력을 본다 — 시각만

펫이 글 쓰는 동안 가만히 있으려면 "지금 타이핑 중인가"만 알면 된다. 그걸 위해
RawInput 으로 **키보드 입력이 있었다는 사실**을 받는다.

- **무슨 키를 눌렀는지 보지 않는다.** 마지막으로 눌린 **시각**만 적어 둔다
- 어디에도 저장하지 않고 기록에도 안 남긴다
- 입력을 **가로채지 않는다**(`RIDEV_NOLEGACY` 를 안 쓴다) — 다른 앱에 그대로 간다
- 마우스는 세지 않는다. 마우스를 움직인다고 글을 쓰는 중은 아니다

관리자 권한도, 손쉬운 사용 같은 별도 권한도 쓰지 않는다.

## 조회 주기

기본 10분이고 1·3·5·10·30분 중에 고를 수 있다. 조회가 나갈 때마다 그 시점부터 다시
세므로, 손으로 새로고침하면 다음 자동 조회도 그만큼 밀린다.

**조회 사이에는 최소 10초를 둔다.** 새로고침을 잇달아 눌러도 그만큼은 안 나간다 —
사용량 API 는 창이 좁아서 그것만으로 요청 제한에 걸린다. 429 가 오면 최대 5분까지
물러선다.

화면이 꺼지면 멈추고, 켜지거나 절전에서 깨어나면 곧바로 한 번 갱신한다.

## 토큰이 만료되면

Claude Code 의 액세스 토큰은 수명이 여덟 시간이라 종종 만료된다. **앱이 알아서
갱신한다** — 같이 들어 있는 갱신용 토큰으로 새 토큰을 받아 제 폴더에 둔다.

갱신용 토큰까지 죽었을 때만 `재로그인 필요` 로 바뀐다. 그때는 트레이 메뉴나 계정 탭의
**Claude Code 재로그인…** 이 콘솔 창에서 `claude auth login` 을 띄운다.

> **맥과 다른 점이 하나 있다.** 맥은 갱신한 토큰을 keychain 에 되돌려 써서 Claude Code
> 로그인이 같이 풀리지 않게 한다. 윈도우는 저장소가 파일이라 동시에 쓰면 섞일 수 있어서
> 아직 안 한다 — 우리 사본으로만 돈다.
