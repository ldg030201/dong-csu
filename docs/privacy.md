# 사용량과 토큰

[← README](../README.md)

## 어디서 읽나

keychain 항목 `Claude Code-credentials`에서 OAuth 토큰을 읽어
`GET https://api.anthropic.com/api/oauth/usage`를 호출하고, 응답의
`five_hour.utilization` / `seven_day.utilization`(각 0~100)을 링에 그린다.

이 조회는 **모델을 부르지 않는다.** 계정 사용량만 읽는 엔드포인트라 토큰을 전혀 쓰지 않는다.

## 토큰을 어떻게 다루나

- `/usr/bin/security`로 읽는다. Apple이 서명한 고정 바이너리라 keychain에서 "항상 허용"을
  한 번 눌러두면 앱을 다시 빌드해도 권한이 유지된다
- **Authorization 헤더로만** 쓰이고 디스크에 쓰거나 로그에 남기지 않는다
- 로컬에 저장하는 건 창 위치, 아이콘·크기 선택, 숨김 여부뿐이다

## 어디에 접속하나

| 대상 | 언제 |
| --- | --- |
| `api.anthropic.com` | 사용량 조회 (기본 10분마다) |
| `raw.githubusercontent.com` | 새 버전 확인과 변경 내역 (하루 1회, 끌 수 있음) |

그 외에는 접속하지 않는다. 통계·추적 없고 외부 Swift 패키지 의존성도 0개다.
버전 탭에서 업데이트 확인을 끄면 Anthropic API 외에 아무 데도 접속하지 않는다.

## 손쉬운 사용 권한

펫의 **입력 피하기**가 켜져 있을 때만 요청한다. 꺼 두면 이 앱은 권한을 아예 묻지 않는다.
뒤 입력창의 글자가 어디까지 왔는지는 이 API 말고는 알 방법이 없다.

**거절하면 이 기능은 아무것도 하지 않는다.** 짐작으로 움직이면 비켜준 게 아니라
제멋대로 도는 것으로 보여서, 어설프게 도느니 안 도는 쪽을 골랐다.
펫 모드의 나머지(혼자 돌아다니기·커서 피하기)는 권한 없이 그대로 돈다.

| | |
| --- | --- |
| 읽는 것 | 지금 글을 쓰는 자리(캐럿)의 **화면 좌표** |
| 읽지 않는 것 | **무슨 키를 눌렀는지**, 입력창의 내용, 창 제목, 화면 그림 |
| 언제 | 마지막 입력 뒤 **1.5초** 동안만. 타이핑이 멈추면 저절로 멈춘다 |
| 어디에 남나 | 아무 데도. 그때 비킬 자리를 정하는 데만 쓰고 버린다 |

**권한 창은 한 번만 뜬다.** 이 권한은 코드 서명에 걸려 있어서 앱을 업데이트하면
허용해 둔 게 풀리는데, 그때마다 창을 띄우지는 않는다. 다시 켜려면 메뉴바 아이콘 메뉴의
**손쉬운 사용 권한 허용…** 또는 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 켠다.

지금 붙어 있는지 확인하는 방법은 [문제 해결](troubleshooting.md)에 있다.

### 권한 없이 읽는 것 하나

글을 쓰는 동안 펫을 멈춰 세우려면 "지금 타이핑 중인가"만 알면 된다. 그건
`CGEventSource.secondsSinceLastEventType`이 주는 **마지막 키 입력 뒤 흐른 초**로
충분하고, 이 값은 권한 없이 읽힌다. macOS가 화면 보호기를 띄울 때 쓰는 것과 같은 값이다.

**무슨 키를 눌렀는지는 이 값에 들어 있지 않다.** 입력 내용을 알 수 있는 통로가 아니다.

## 조회 주기

기본 10분이고 1·3·5·10·30분 중에 고를 수 있다. 조회가 나갈 때마다 그 시점부터 다시 세므로,
수동으로 새로고침하면 다음 자동 조회도 그만큼 밀린다.

화면이 꺼지면 멈추고, 켜지거나 절전에서 깨어나면 즉시 한 번 갱신한다.
429가 오면 최대 5분까지 백오프한다.

유휴 상태에서 쓰는 자원은 CPU 0.2% 안팎, 메모리 22MB(`phys_footprint`) 정도다.
CPU·메모리 표시를 켜면 2초마다 표본을 떠서 조금 더 쓴다.

## 토큰이 만료되면

Claude Code의 액세스 토큰은 수명이 8시간이라 종종 만료된다. 그러면 링과 숫자가 흐려지고
오른쪽 아래가 `재로그인 필요`로 바뀐다. **화면의 숫자가 지금 값이 아닐 때 그 사실을 숨기지
않는다.** 메뉴의 `Claude Code 재로그인…`을 누르면 터미널에서 로그인 플로우가 열린다.

이 앱은 토큰을 스스로 갱신하지 않는다. keychain에 리프레시 토큰이 같이 들어있지만, 리프레시
토큰은 사용할 때 회전되는 경우가 많아서 우리가 먼저 쓰면 Claude Code가 들고 있던 값이
무효가 되고 Claude Code 로그인이 풀릴 수 있다. 갱신은 Claude Code에게 맡긴다.
